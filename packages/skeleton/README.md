# @leon8ix/skeleton-v2

The complete Skeleton v2.11.0 component library, migrated to native Svelte 5 while retaining the v2 design.

See the [fork documentation](https://github.com/leon8ix/skeleton-v2/tree/modernize-v2) for setup, callback/snippet migration, archived upstream documentation, and validation commands.

Use with `@leon8ix/skeleton-v2-tailwind`. The original Skeleton MIT license is included.
