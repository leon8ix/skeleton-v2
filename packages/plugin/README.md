# @leon8ix/skeleton-v2-tailwind

Skeleton v2 themes, tokens, and CSS for Tailwind CSS 4. This is an independent maintenance fork of the official `@skeletonlabs/tw-plugin@0.4.1`.

See the [fork documentation](https://github.com/leon8ix/skeleton-v2/tree/modernize-v2) for setup. Use the named `skeleton` export in the Tailwind configuration, import `src/styles/preflight.css`, and run the exported `skeletonV2Spacing()` PostCSS plugin after Tailwind compilation to preserve v2 layouts.

The original Skeleton MIT license and the license for the retained Tailwind reset/defaults are included.
